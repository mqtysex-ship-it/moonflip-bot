# Live Chat Implementation Plan

**Goal:** Add a right-side web chat using the existing Discord-linked identity and level, with level 2 required to post.

**Architecture:** Store committed messages and rate limits in the private Supabase PostgreSQL schema. Authenticate writes with the existing web session, read the level from the wallet in the transaction, and deliver committed messages over the existing SSE stream; reconnect reloads durable history. Guests can read but cannot post. Use text-only rendering and parameterized SQL.

**Technology:** Express, PostgreSQL, existing SSE and vanilla web UI.

- [x] Add a private migration with RLS and revoked public privileges; serialize per-user writes and preserve idempotency across retries.
